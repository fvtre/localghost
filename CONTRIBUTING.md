# Contribuir a LocalGhost

Gracias por ayudar a mejorar LocalGhost. Los cambios deben conservar el procesamiento local y explicar cualquier conexión nueva que transmita datos.

## Antes de enviar un cambio

1. Abre un issue para cambios grandes o nuevas integraciones.
2. No incluyas secretos OAuth, tokens, audio, transcripciones reales ni archivos `.env`.
3. Mantén TypeScript y Rust tipados y separa la lógica de la interfaz cuando sea razonable.
4. Describe qué cambió, cómo se verificó y cualquier requisito adicional para Windows.

## Desarrollo local

Consulta [README.md](README.md) para instalar Ollama, Whisper y ejecutar la app. La beta de escritorio requiere Windows, Rust con MSVC y Microsoft C++ Build Tools.

## Reportar seguridad

No publiques vulnerabilidades sin corregir. Sigue las instrucciones en [SECURITY.md](SECURITY.md).
